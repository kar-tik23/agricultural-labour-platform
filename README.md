# Agricultural Labour Access Platform

A mobile platform for helping farmers discover nearby agricultural labour and service providers based on:

- Crop
- Required agricultural work/skill
- Availability
- Geographic proximity

## Planned Technology

- Flutter
- Spring Boot
- MySQL

## Core Users

- Farmer
- Service Provider
  - Individual Labour
  - Labour Group
  - Contractor
- Admin

## V1 Goal

Find the right agricultural worker quickly and enable direct contact.
